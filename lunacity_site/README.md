# Lunacity 公式サイト（複数ページ版）

## 開き方
`index.html` を開いてください。ホーム・Lunacityについて・サーバールール・職業紹介・参加方法・FAQは、それぞれ独立したHTMLページです。

## 設定
- `config.js`: Discord招待URLを設定
- `rules.js`: 正式なルールを追加
- `multipage.css`: 追加のデザインとアニメーション
- `site.js`: ハンバーガーメニュー、ルール検索、モーダル、フォーム、スクロール演出
- `assets/`: 提供されたバナー・サーバーアイコン

## ホワイトリスト申請の重要事項
現在の申請フォームは**フロントエンドのみ**です。入力内容の確認・コピーはできますが、サーバーやDiscordへは送信しません。実際の受付には、サーバー側API・Discord Botなどの送信先、認証、スパム対策、個人情報の取扱方針が必要です。公開時に誤解がないようフォームにも未送信である旨を明記しています。

## パフォーマンス
`transform`/`opacity`主体の軽量演出、IntersectionObserver、reduced-motion対応です。60fpsは保証できず端末・ブラウザに依存します。
